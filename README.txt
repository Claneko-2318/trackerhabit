TRACKER PERSONALE — VERSIONE 18 FUNZIONANTE

COME APRIRLO
Per condividere correttamente dati e impostazioni tra tutte le pagine, il tracker deve essere aperto tramite un indirizzo web locale o un hosting statico, non facendo doppio clic sui singoli file HTML.

Windows:
- apri AVVIA-TRACKER-WINDOWS.bat

Mac / Linux:
- apri AVVIA-TRACKER-MAC-LINUX.command
- oppure esegui: python3 avvia_tracker.py

Il browser aprirà http://127.0.0.1:8765/index.html
Per spegnere il server, chiudi la finestra del terminale.

SALVATAGGIO
- Tutte le sezioni salvano i dati automaticamente nel browser.
- Sonno, Cibo e acqua, La mia giornata e Tetr-Emotion usano lo stesso archivio.
- Home, Statistiche e Archivio leggono i dati reali registrati.
- Impostazioni permette di esportare e importare un backup JSON.
- Il collegamento a Google Sheets è facoltativo e aggiunge la sincronizzazione online.
