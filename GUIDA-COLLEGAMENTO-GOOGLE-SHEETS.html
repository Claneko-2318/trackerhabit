Salvataggio online facoltativo

Collegare il tracker a Google Sheets

Il tracker salva già tutto nel browser. Il collegamento al foglio Google aggiunge una copia online e permette di recuperare gli stessi dati dopo aver sostituito o svuotato il browser.

Prima di iniziareServono un foglio Google vuoto, il file Code.gs incluso nel progetto e l’URL finale della Web App.
1

Crea il foglio Google

Apri Google Sheets e crea un nuovo foglio vuoto. Puoi chiamarlo, per esempio, Tracker personale. Non devi preparare colonne o tabelle: lo script creerà da solo la scheda tecnica TrackerData.

2

Apri Apps Script

Nel foglio scegli Estensioni → Apps Script. Si aprirà l’editor dello script associato a quel foglio.

3

Inserisci il codice

Apri il file google-apps-script/Code.gs incluso nel progetto. Nell’editor di Apps Script elimina il contenuto già presente, incolla tutto il nuovo codice e premi Salva.

Apri Code.gs
Mostra il codice direttamente qui
const TRACKER_SHEET = 'TrackerData';
const CHUNK_SIZE = 45000;

function doGet(e) {
  try {
    const action = String((e && e.parameter && e.parameter.action) || 'ping');
    if (action === 'ping') {
      return json_({ ok: true, message: 'Tracker personale collegato', time: new Date().toISOString() });
    }
    if (action === 'getState') {
      return json_({ ok: true, state: loadState_() });
    }
    return json_({ ok: false, error: 'Azione GET non riconosciuta.' });
  } catch (error) {
    return json_({ ok: false, error: error.message });
  }
}

function doPost(e) {
  try {
    const payload = JSON.parse((e && e.postData && e.postData.contents) || '{}');
    if (payload.action === 'saveState') {
      saveState_(payload.state || {});
      return json_({ ok: true, savedAt: new Date().toISOString() });
    }
    return json_({ ok: false, error: 'Azione POST non riconosciuta.' });
  } catch (error) {
    return json_({ ok: false, error: error.message });
  }
}

function getTrackerSheet_() {
  const spreadsheet = SpreadsheetApp.getActiveSpreadsheet();
  let sheet = spreadsheet.getSheetByName(TRACKER_SHEET);
  if (!sheet) sheet = spreadsheet.insertSheet(TRACKER_SHEET);
  return sheet;
}

function saveState_(state) {
  const sheet = getTrackerSheet_();
  const json = JSON.stringify(state || {});
  const chunks = [];
  for (let index = 0; index < json.length; index += CHUNK_SIZE) {
    chunks.push([chunks.length + 1, json.slice(index, index + CHUNK_SIZE)]);
  }

  sheet.clearContents();
  sheet.getRange(1, 1, 1, 3).setValues([['Parte', 'Dati JSON', 'Ultimo salvataggio']]);
  if (chunks.length) {
    const savedAt = new Date();
    const rows = chunks.map(([part, data]) => [part, data, savedAt]);
    sheet.getRange(2, 1, rows.length, 3).setValues(rows);
  }
  sheet.setFrozenRows(1);
  sheet.hideColumns(2);
}

function loadState_() {
  const sheet = getTrackerSheet_();
  const lastRow = sheet.getLastRow();
  if (lastRow < 2) return null;
  const rows = sheet.getRange(2, 1, lastRow - 1, 2).getValues();
  const json = rows
    .filter(row => row[1] !== '')
    .sort((a, b) => Number(a[0]) - Number(b[0]))
    .map(row => String(row[1]))
    .join('');
  return json ? JSON.parse(json) : null;
}

function json_(value) {
  return ContentService
    .createTextOutput(JSON.stringify(value))
    .setMimeType(ContentService.MimeType.JSON);
}
4

Crea una nuova distribuzione

Nell’angolo in alto a destra scegli Esegui il deployment → Nuovo deployment. Accanto a “Seleziona tipo”, apri le impostazioni e scegli App web.

5

Configura l’App web

Come descrizione puoi scrivere “Salvataggio tracker personale”. Imposta Esegui come: me. In Chi ha accesso scegli l’opzione che consente l’accesso a chi possiede il collegamento, normalmente Chiunque.

Questa scelta è necessaria perché le pagine HTML possano comunicare con lo script senza mostrarti ogni volta una schermata di accesso.

6

Autorizza e distribuisci

Premi Esegui il deployment. Google potrebbe chiederti di scegliere il tuo account e autorizzare lo script ad accedere al foglio. Completa l’autorizzazione usando lo stesso account proprietario del foglio.

7

Copia l’URL corretto

Al termine copia l’URL dell’app web. Deve terminare con /exec. Non usare l’indirizzo di test che termina con /dev.

8

Collega il tracker

Apri Impostazioni → Dati. Nella sezione “Collegamento a Google Sheets” incolla l’URL e premi Verifica collegamento. Quando compare il messaggio verde, premi una volta Invia dati locali.

Apri Impostazioni
9

Da questo momento è automatico

Ogni modifica viene salvata subito nel browser e, quando il collegamento è attivo, sincronizzata anche con il foglio. Il pulsante Carica dal foglio recupera e unisce la copia online con quella locale, mantenendo per ogni giornata la versione modificata più di recente.

Apri il tracker dal launcher

Per condividere il salvataggio tra tutte le pagine, usa AVVIA-TRACKER-WINDOWS.bat oppure AVVIA-TRACKER-MAC-LINUX.command. Evita di aprire i singoli HTML con doppio clic.

Ordine della prima configurazione

  • Verifica collegamento
  • Invia dati locali
  • Continua a usare normalmente il tracker

Tieni privato l’URL

La Web App è il collegamento ai tuoi dati. Non pubblicare l’URL /exec e non inserirlo in screenshot o file condivisi.

Dopo una modifica a Code.gs

Apri Esegui il deployment → Gestisci deployment, modifica la distribuzione, seleziona una nuova versione e distribuisci di nuovo. L’URL /exec normalmente resta lo stesso.

Se non si collega

  • Controlla che l’URL finisca con /exec.
  • Verifica di aver scelto l’accesso “Chiunque”.
  • Ridistribuisci una nuova versione dopo aver modificato il codice.
  • Prova prima ad aprire l’URL in una nuova scheda: deve comparire una risposta JSON.
